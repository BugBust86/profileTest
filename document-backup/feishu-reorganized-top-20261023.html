03 · 结果归纳与指标口径

3.1 · 本次结果归纳

  • CPU 与内存：两组数据中，同设备、同档位开启超分后的 App CPU 与 App 内存使用率均高于关闭；第二组 App PSS 也均增加。整机 CPU、总内存同时受后台负载影响。
  • 电荷量：第二组 4 个设备与档位组合中，开启超分时的电荷量消耗均更高。Pixel 7 的 120P / 240P 分别由 62 / 64 mAh 增至 112 / 152 mAh；OnePlus Ace5 分别由 52 / 50 mAh 增至 72 / 190 mAh。
  • 帧耗时：历史记录中，Pixel 7 的 120P / 240P 为 27 / 81 ms，OnePlus Ace5 为 20 / 53 ms；240P 平均处理耗时高于 120P。
  • 比较边界：每个场景为单次 5 分钟采集，未做重复实验或误差统计；差值不直接等同于超分独立开销，也不据此推断跨设备能效排名。

3.2 · 指标计算与测量说明

  • CPU：App CPU（整机）与总 CPU 均为 0–100% 口径，8 核合计为 100%；App CPU（单核）单独列示，可超过 100%。仅统计名称恰好等于包名的主进程，不包含 :suffix 子进程。
  • 内存：App 内存 = PSS / MemTotal；总内存 =（MemTotal − MemAvailable）/ MemTotal；App PSS 单位为 MiB。CPU、内存均为样本算术平均值。
  • 电荷量：消耗 = 起始 − 结束；仅起止两次读取设备电量计，非电流积分。读数与起止放电状态有效，仍不能证明中途未充电；存在刷新间隔、量化误差，应在同设备、同条件与时长下比较。实际观测间隔单独列出。
  • 帧耗时：表中单位为 ms，原始截图 AverageTimeUs 单位为 μs；第 04 节保留采样帧数、最短耗时及截图。480P 仅作历史参考。
